# Курс повышения квалификации «Практика командного исследования»

Публичный frontend личного кабинета курса.

В репозитории намеренно нет backend-кода, приватных справочников, тестовых участников, email администраторов и других служебных данных.

Актуальная версия frontend подключена к опубликованному Apps Script backend и публикуется через GitHub Pages.
